# ReAvPlayer module provenance

The packaged `modules/reAvPlayer.suprx` has SHA-256:

`8b6d26c97b7e9a3b24ae69d2eadf1f6e7223102dcc375b9ca30e466815a04850`

It is the module blob tracked by SonicMastr/Vita-Media-Player commit
`0b5e7c933196227f955588c806c51b0b66c10654`. At that commit the module has Git
blob ID `d0a8df61bed6bc7920b044b099fa63f51a9f5db4`.

The corresponding ReAvPlayer source repository is SonicMastr/ReAvPlayer at
commit `abff24a21ffec3e57fc1cd3b1d17dc26666251b0`, licensed under MIT by Jaylon
Gowie. That source was originally built with Vita Development Suite rather
than VitaSDK. The exact binary is preserved for compatibility; replacing it
requires recording a new source commit, build recipe and binary hash.
